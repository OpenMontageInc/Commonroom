# Code of conduct

Commonroom follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we want participation in this project to be a harassment-free
experience for everyone. Be respectful and constructive, assume good faith,
accept feedback gracefully, and focus on what is best for the community.
Harassment, insults, personal or political attacks, sexualised language or
imagery, and publishing others' private information are not acceptable.

The full text, including the enforcement guidelines we follow, is at the link
above. It applies in all project spaces (issues, pull requests, discussions)
and when representing the project elsewhere.

## Reporting

To report unacceptable behaviour, contact the maintainers privately through
GitHub, using the repository's
[private reporting form](https://github.com/OpenMontageInc/Commonroom/security/advisories/new)
and start the title with "Conduct:". It reaches only the maintainers
([@calesthio](https://github.com/calesthio)). Reports are handled confidentially.
Maintainers may remove, edit or reject contributions, and temporarily or
permanently ban contributors, for behaviour they find inappropriate.
